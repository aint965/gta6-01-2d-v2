PALKON AUTO — a 2D top-down GTA-style game set in Solmar, a sun-baked coastal city. Drive the boulevard, run four story jobs for Mara Venn against Bastion Civic, dodge the patrols as your HEAT rises, and tune in to SOLMAR FM. Four missions, $2,000 on the line, one city.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080

Drive with W/S (throttle / brake-reverse) and A/D (steer), SPACE for the handbrake, E to enter or exit a car, H for headlights, 1/2/3 to switch the time of day. The mission timer starts only when you first move.
